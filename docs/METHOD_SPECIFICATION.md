# Static two-stage DiD specification

Primary sources: Gardner, Thakral, Tô and Yap, *Two-stage differences in differences*, June 2026, https://linh.to/files/papers/2sdd.pdf; original Gardner working paper arXiv:2207.05943. Software comparators are Kyle Butts' official R did2s commit cde84687aecfc11b949fbd5bd56fea1992fb76a0 and Stata did2s commit 976959bbf9f6ca4d7d8b45813bcf7ca9e8064724. External sources remain validation-only.

Let X contain all state indicators, T-1 time indicators, and optional ordinary covariates. Let D indicate treated post observations and U=1-D. With positive observation weights W, estimate beta=(X'WUX)^(-1)X'WUY. Predict X beta on all observations. The second stage is the no-intercept WLS of Y-X beta on D: theta=D'W(Y-X beta)/(D'WD). No treatment regressor enters the first stage. No implicit sample deletion occurs: invalid/nonfinite inputs, missing prediction levels and unidentified models fail explicitly.

The transparent oracle builds X on small samples and uses weighted least squares. Production code collapses weighted X/Y cross-products by state-period, eliminates state effects with a Schur complement, and solves only for time/covariate effects. Assignment-specific untreated masks update every first stage. Delete-one-state estimates subtract that state's within-state cross-products before solving. Covariate ill-conditioning invokes a FEABSORB-1 projection fallback rather than trusting unstable normal equations. The explicit oracle is bounded at five million matrix entries; it is not the large-sample backend.

FEABSORB-1 is independently vendored: weighted group demeaning, cyclic additive projections, scale-relative maximum group-mean convergence, multiple RHS, cached codes and weight sums. Singletons are reported, retained in the projection, and handled for estimand validity at the estimator layer. Disconnected untreated systems are conservatively rejected in this release. Default fallback tolerance is 1e-13 and maximum iterations 10,000. Nonconvergence returns an explicit inference error.

The static coefficient averages treated-post adjusted outcomes using observation weights. With the same untreated model and scalar aggregation it equals the BJS point estimate; this does not imply equal analytic covariance estimators. The BJS default centers treated residuals within cohort-time groups, while did2s uses the static second-stage score.

Jackknife uses sqrt((G-1)/G * sum((theta_-s - mean(theta_-s))^2)), scalar t=(theta-null)/SE, two-sided Student t(G-1). Every deletion refits the untreated model and recomputes the surviving scalar aggregate. A cohort may disappear when that aggregate remains estimable. An undefined deletion remains a failure; G is not lowered and unsuccessful deletions are not discarded. RI permutes whole state timing labels preserving cohort sizes. Exact support enumeration is used when requested draw count covers support; otherwise unique nonobserved assignments are sampled. Inclusive |theta_assignment| >= |theta_observed| tails and plus-one correction are explicit. Replace recalculates first stages and all inner jackknifes. Subtract constructs Y-theta_full D_observed once and holds it fixed through all assignments/deletions. Its heterogeneous-effect behavior is diagnostic, not proof of sharp-null validity. Add is not part of the intended API.
